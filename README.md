# Landingpage Restaurante Mexicano y comida Internacional
La pagina consume API de recetas de platillos internacionales.

# Sección de recetas
Se puede realizar busqueda por platillo y muestra las recetas.

# Sección de Blog
Se tiene una sección de Blog en la que se puede encontrar recetas de usuarios.

# Formulario para reservaciones
Se puede hacer una reservación por medio de la sección.
